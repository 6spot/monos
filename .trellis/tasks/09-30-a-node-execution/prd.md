# Single-Node execution, artifacts and recovery

## Goal

Run a published Node with current Role context and produce a recoverable local REVIEW result.

## Requirements

- Schedule canonical Plan membership through existing shared capacity with current Role instructions, effective Specification, Node goal, Project map and relevant formal context.
- Implement managed optional Artifact publication/read, block_node and explicit recovery; completion does not require an Artifact or a fabricated repository result.
- Finalize opened workspace through trusted recoverable Git effects before recording current completion evidence and REVIEW.
- Preserve private dirty work through Stop/Continue and same-Node retry; do not interpret runtime exit/prose as completion.

## Acceptance criteria

- [ ] Native published Node reaches REVIEW only from formal completion after physical settlement; actual result tree matches committed input/output evidence.
- [ ] Artifacts remain scoped/readable after producer exit/reconnect; no-resource work has honest completion without fixture commits.
- [ ] Crash/replay, missing outcome, blocker, Stop/Continue and stale activation cannot double-dispatch or manufacture current evidence.
