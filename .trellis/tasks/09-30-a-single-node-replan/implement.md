## Ownership and concurrency

Backend owns apps/server, packages/db, packages/domain, packages/protocol and root
DB entrypoint. Runner owns runner/**. Root owns task/spec/native helpers/host work.
Reviewer fixtures and process workers receive explicit file assignments. Shared
checkout: no reverting another owner's edits, no recursive delegation, no new service
or push. Existing accepted host Task remains idle; create fresh acceptance Tasks.

## Risk checkpoints

- Request freeze cannot silently kill or invalidate independent live Node authority.
- One shared Planner claim; every dedicated phase has exactly one terminal outcome.
- Joint insufficient requirements never pass standalone Spec publication or annex
  another operation's slot; existing sufficient behavior and migration20 stay intact.
- New Node identity requires explicit historical private-work transfer at backend
  and Host; retain process isolation, checkpoint and fixed Git ancestry.
- Retained identity is not evidence applicability; preserve all old immutable bases.
- Dismiss/withdraw/Owner Stop/guidance remain separate; no fake feedback subsystem.
- Bounded reads/queues/pumps remain fair, and stale input cannot be laundered by CAS
  version substitution. Record failures honestly and recover exact original IDs.
