## Goal

Establish one fresh Owner-originated repository execution through the final
installed browser, from passive capture to exact local REVIEW, and close the
Task execution package using revision-specific accepted evidence.

4. Preserve full noncredential requests, receipts, source/Attempt/Spec/Plan/Node/

   No fixture admission, SQL lifecycle writes, fake acknowledgements or driver-

5. Map package Owner exits/reconnect/restart to their accepted native/deterministic/

   Reload current UI; do not repeat the historical Replan/reboot/fault tour.
6. Preserve prior Task results, receipts and monolab18443. Settle every new owned
   process/effect/input/lease/outbox, retain successful REVIEW and all failures,

## Scope limits

No remote push/PR/merge/delivery or Owner final acceptance; no new permanent service,
host reboot, Runtime install/login, generic workflow engine, new domain concepts,
mandatory native session resume or cross-Runner migration. Product changes are
only justified by an observed defect and must receive a scoped review/regression.
No unresolved product decision blocks planning; external observations are gates.
