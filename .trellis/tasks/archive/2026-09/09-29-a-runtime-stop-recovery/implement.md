## Risk and rollback points

- Stop after an admitted completion can create mutually waiting terminal operations; the transaction must detect and return the existing result instead of admitting another Stop.
- A delayed Start can be in flight even if the queued Start outbox was marked done; preserve the reservation and send a tombstoned Stop until physical absence is proved.
- Host reboot affects the old service too. Inspect its activity immediately before reboot and preserve its volumes/units; cancel the trial if it is doing unrelated work. The probe's 300-second hold is a deadline, never permission to skip preflight.
- Retry has no general semantic Context Builder yet. This leaf proves safe eligibility and selected successor admission with current canonical fixture input; the later Task-execution package supplies the full conversation-aware context before production automatic rescheduling.
